## 1. 設定の状態と正本

**確定**は作者が採用した設定、**方向性**は採用した設計方針で詳細が未定のもの、**候補**は未採用の案、**未決定**は答えを置いていない項目を指す。不採用・撤回された説明も、同じ案を再導入しないため履歴として残す。

さらに、作者の採否、作中人物の知識、実行システムへの反映を分ける。作者が決めた真相を住人全員が知るとは限らず、作者にも未定の真相を「住人に秘密なだけ」と扱わない。設定の採用は、事件の発生や実装完了でもない。

WORLDは自然法則・地理・生物・社会・存在とその状態を持つ。CHAR／COREは人格・記憶・意思決定を持ち、StoryPlayerは作品方針・巻構成・事件構想・伏線・原稿・演出を持つ。この作品の設定は、エージェントの生活世界へ自動で適用する共通法則ではない。元資料の `canon=false` はLive Timelineへの混入を防ぐ境界であり、作品内の確定設定が虚偽という意味ではない。

10月14日版のWORLDレジストリは165件、StoryPlayerは48件。WORLDは確定115、方向性12、候補9、未決定29である。ただし、これらは**履歴や包括的な未定項目を含むレコード数であり、独立した確定法則の数ではない**。全件が実行基盤への未公開状態である。WorldSpecには町1、人物3、楽器1があり、Action・Ruleは空、初期WorldState／Snapshotは未作成。稼働済みの世界を表すデータではない。

## 2. 自然環境と異世界転移

通常の物理法則は地球準拠とし、標準地表重力を**8.0 m/s²**とする。大気の主要組成と標準地表気圧は地球とほぼ同じだが、厳密な混合比・基準気圧・高度分布は未定である。地球と異なる微量成分は候補で、存在、性質、魔法との関係を確定していない。

動物・人型生物は地球と概ね同程度の大きさ。地球出身者は、同程度の体格の現地人より質量や筋力がやや大きい場合があるが、全員には当てはめない。異世界へ来ると地球にいたときより重量が増す、という意味ではない。植物は類似する地球植物より大きく育つ傾向があり、低重力がそれを支える設定を採用する。全種共通の倍率・速度はなく、地球で実証された普遍的な成長則として説明しない。

転移は肉体を伴う方式で、転生ではない。生存可能かつ交配可能な生物学的条件を満たす先で成立する。出身世界は地球だけではなく、転移者の社会的呼称を**チェンジリング**とする。変身能力や一つの種族分類を意味しない。存在割合は概ね1万人に1人であり、年間発生率ではない。

外見で出自がわかる者とわからない者がいる。主人公は外見だけでは判別できない。住民は転移者の存在を漠然と知る一方、身近にいるとは思いにくい。転移者は生物多様性に寄与するが、交配相手・子孫の性質・遺伝的機構は未定。「不適合な転移者は死ぬ」という話の存在は採用するが、その内容の真偽や死亡の実例を確定しない。転移先の選別機構・主体・言語習得は未決定である。

## 4. 文明水準・五系統・生活魔法

都市の一般水準は**第一次産業革命期相当**、農村は中世寄り。都市の設備と魔法の実用化が産業化を支え、少数の卓越した開発者がその先の魔導技術を生む。実務層が成果を設備・サービスへ展開する。農村の技能を低く評価する設定でも、都市住民の生来の優越でもない。「産業革命期相当」から鉄道、銃、銀行、近代医学等の存在を自動で決めない。

国家の一般的な開発方向は、軍事とそれに付随する医療、生産、生産を支えるインフラの順とする。ただし固定的な優先順位ではなく、地域の生存課題によって重点が変わり、砂漠国家では水確保が最重要になる。これは採用済みの方向性であり、国別の研究予算や制度の確定ではない（統合仕様§6.3、`world_setting_0148`）。

基礎魔法は普遍的で、一般人には**火・水・風・木・土**の全五系統の素養がある。学力・体力・器用さのような個人差があり、全員が高等術式を使えるわけではない。習得年齢、転移直後の習得条件、例外者は未定。五系統が自然界の排他的な根本構成要素かどうかも未定で、少数の特殊魔法が存在する。

| 系統 | 採用した作用・用途 | 未決定の主要部分 |
|---|---|---|
| 火 | 薪など生活燃料への着火 | 高度な加熱方式・高温炉の性能 |
| 水 | 個人が生活に足りる水を容器にためる | 量・速度・原料・生成機構・共同利用 |
| 風 | 指定した空間の空気を動かすB方式。自然風と併用 | 距離・風速・風量・時間・反作用・収支 |
| 木 | 基本魔法の一系統として存在 | 具体用途。農業魔法との分類対応も未確定 |
| 土 | 土砂・岩石・鉱石等を操作。専門家は金属を含む素材そのものを操作。エンチャントは土魔導 | 精密加工・物性変更・合金化・付与効果 |

魔法実行装置には、人工魔導回路・魔導素子型と、生体組織・人工回路の融合型を採用している。ただし、個人が基本魔法を使うとき体内装置や外部器具が必須かは未決定である。

日常の水汲み・家庭配管は必須ではない。一方、基本水魔法だけで農業・工業の全量用水を代替せず、通常の生産にはまとまった水源と供給が必要になる。「人数を集めれば必ず工業水を得られる」「人数を集めても絶対に無理」のどちらも未採用である。生活に使えることと、医療用純度・殺菌性能の保証も分ける。

調理は燃料を燃やし、着火を魔法で行う。基本魔法が調理熱を全量供給する設定ではないが、高度な魔法加熱技術まで禁止していない。

農業魔法は生育の安定化と弱った部分の大まかな補助・補修を行う。作物だけを精密に選べず、雑草や害虫にも良い作用が及び得る。除草・害虫管理・畑の世話は農民の主要な仕事として残る。水・風は局所的な不調をある程度補助できるが、基礎農業魔法で台風や大規模な害虫発生を防ぎきれない。被害ゼロ、肥料不要、急速成長、収量倍率を追加しない。これは先端魔法全般の絶対上限を決めたものではない。

## 5. 魔法力と砂漠都市

魔法力は、魔法の成立・維持・規模・個体差を探究するための作業概念である。技能、知識、出力、供給源、資源量を初めから一つの数値に統一しない。現地には熟練者・工房・大学・高度な装置が存在し、「実用化できる」と「根本原理まで説明できる」を分ける。

| 層 | 現行設定 |
|---|---|
| 採用した現象 | 休息の後に再び魔法を使える状態になる現象がある |
| 採用した社会認識 | 現地では「使った魔力は休息で回復する」と広く説明される |
| 作者にも未定の真相 | 資源の補充、身体・認知の回復、作用源への再アクセス、複合要因等のどれか |
| 未設定の数値 | 個人容量、補充速度、必要休息時間、持続時間、産業運転周期 |

使用総量には実用上の制約がある。しかし、共有MPプールや毎分の物理的補充は未採用である。疲労回復説も、魔力補充説に代わる確定答案ではない。物質・エネルギー収支は未決定で、魔法を既知の地球物理だけに還元する義務も、無から無限生成する設定も置かない。

砂漠国家では、水確保を先端研究の最重要課題とする。**魔法そのもののブレイクスルーが実用化され、すでに都市の成立を支えている**。普通の井戸・地下水探査・貯水施設だけで核心を説明する案は不採用だが、配水・貯蔵等の付帯設備は併存できる。

水の原料・変換過程・大量化条件・供給範囲・費用・普及条件は未定。「水を分子段階で合成・再構成している」「大量化の鍵が魔法力」は候補である。全砂漠に地下水や水蒸気がないとはせず、対象都市が通常の水利用だけでは成立しにくかった、と整理する。砂漠全体の緑化や他国による模倣の絶対禁止も未採用。

出典：`S35/docs/統合仕様_v1.3.5.md` §10–11、`S35/WORLD/environment_baselines/magic_power_v1.3.2.json` の `rest_and_reuse`・`research_parameters`、WORLD設定 `0160–0169`・`0181`。

## 6. 産業動力・道路・水運

工業の回転動力は河川水車と風車を基盤とし、とくに風車が主力。自然風と魔法風を利用するが、全施設へ無制限の一定風が供給されるわけではない。個人の身近な移動には、背に風を受けて走るキックスケーター状の車両が普及している。

陸上の重量貨物は主として家畜牽引や駄獣、まとまった大量輸送は河川船・帆船が担う。魔法風を広く補助動力に使う。陸上重量貨物を風力だけで大量輸送する用途には向きにくく、船では浮力を利用できる。帆船に機械式推進装置を搭載しない。風車の回転を車輪へ伝える陸上車両は候補である。

内燃機関という概念は未成立。蒸気機関は回転・推進の原理を利用できるが、鉄鋼・機械工業が豊かな国で試験運用される段階であり、普及済みの蒸気船・鉄道網はない。試験場所・出力・効率・量産条件は未定。

主要道路の建設負担は国力と利益に左右される。富裕国が他国の集積拠点まで自費で建設することもあり、力関係により弱い国が負担する場合も多い。どちらも一律義務ではない。完成後の維持は、建設出資者よりも管轄領地の管理者の責務による。「国・県・荘」は類比で、正式な行政名称ではない。

風を受ける車輪交通が重要なため、地球中世より舗装が広く普及する。農村にも舗装された重要路があるが、全道路の舗装は決めていない。管理網外は踏み跡・獣道が基本。未舗装に対応する車輪もあり、大径化が段差への走破性に役立つ。2・4・6輪や無限軌道の具体的普及は候補で、材質・幅員・舗装率・車両性能は未定。

水運は自然河川の航行可能区間が基本で、整備は船着場・港湾を中心とする。大規模な運河・閘門網を一般基盤とせず、水深・流れ・季節・積替の制約を残す。個別の例外を全面禁止したわけではない。港湾の管理権・利益は領主が保持し、維持も領主の責務。利益を守る動機はあるが、全港が常に完全な状態だとは保証しない。

## 7. 生産・集積・食料の経済構造

都市は、生産・交易の目的、水、食料、交通接続、維持条件から設計する。河口や合流点などの好立地だけで人口を決めない。生活水を個人魔法で満たせても、農工業の必要量を別に確保する。

生産物集積拠点は、領主が土地・施設の管理権を持ち、商人・商会が集荷・保管・売買・輸送を担う分担方式である。施設建設費、維持費、利用料、参入条件は未定。食料は地域ごとの自給と広域交易を併存させ、農村は地元生産を基盤とする。大都市・工業地・生産条件の厳しい地域では、外部供給が重要になり得る。自給率、純輸出入、取引先は未設定。

農耕・畜産・酪農・放牧の選択は、**第一に土地の自然適性、第二に市場需要・売れやすさ**による。気候、水、地形、土壌、植生、標高に合う候補の中で、価格・輸送費・保存条件を考える。同じ地域内で複合利用してよく、人工的な均等比率を強制しない。放牧を一般的な土地利用として採用し、水場や冬季飼料の制約を残す。10地域の具体的生産量・家畜頭数・酪農量・加工保存・供給先は未定である。

## 8. 古代文明と技術探究

古代魔導文明は経験的な試行錯誤で高度な技術を築き、自律的に自己改良する魔導システムを生み出した。システムは設定された目的に沿って改良するが、その目的そのものを自由には変更できない。改良の結果、内部は人間に理解困難なブラックボックスになった。初期目標の設定方法や変更不能条件は未定。

特定技術者への過度な依存と継承断絶が、技術体系の喪失理由である。一方、文明全体の崩壊原因は別の未決定事項であり、両者を同じ事件と断定しない。現代文明が測定・理論化・標準化・継承に強みを持つのは採用した方向性。古代都市管理システムの所在・稼働状態・魔法力との具体的接続は未決定である。

## 9. 主人公・第一話・シリーズ構想

### 9.1 作品の核と人物

作品の核は「面白い物語を追っているうちに、技術の奥深さにも引き込まれる小説」。第1話は主人公を好きになってもらうことを優先し、技術紹介のために事件を起こさない。

主人公は地球・日本出身で、ソフトウェア・情報処理・システム設計・問題解析を専門とした技術者。転移から数か月〜数年後、小さな町で便利屋として暮らす。面倒見がよく、中心的な原動力は好奇心。違和感を見つけると夢中になり、本来の期限を忘れかけるが、失敗から逃げない。現地の才能に敬意を払い、魔法知識では見習いに劣る場合もある。万能な技術者にはしない。

恩人は転移初期に食事・寝床・仕事で支えた演奏家で、今は家族に近い。見習いは主人公を慕い、仕事を手伝い、独自の発見もする。三人の名前・年齢・外見、恩人と見習いの性別などは未定。恩人の音楽伝承者としての役割、主人公の記録が世界に存在しないという謎は候補である。

人格の正本はCOREが所有する。既存WorldSpecの `public_background` にある地球出身等を、キー名だけで全住人の既知情報にしない。作者設定、各人物の知識、読者への開示は別に扱う。

### 9.2 第一話「祭りと魔導楽器」

町では祭りがあり、住民は恩人の演奏を楽しみにしている。希少な魔導楽器は専門技能を必要とし、通常は聴き手それぞれの記憶の情景を心に浮かばせる。卓越した奏者は自分の情景を共有できる。物理的な幻影が現れるかは未定。

第一話では、音楽としての質は保たれるのに、情景喚起だけが働かなくなる。恩人は腕が衰えたと思い、祭りへの出演を諦めかける。主人公は音楽と恩人の自信を守るため原因を調べる。ある日を境に異常が確認されたことを手がかりにするが、希少な楽器・奏者を交換する単純な比較は難しい。

最後の正常を示す手がかりは、A「子どもが情景を描いた絵」、B「練習の休憩前後」、C「主人公が地球の情景を思い出した演奏」が候補で、未選択。原因、異常条件、調査・修理法、祭りの結末、第1巻の謎との直接接続も未定。楽器の観測上の不調、恩人の解釈、主人公の疑問、真相を分ける。これらは採用した事件構想であり、発生済みWorldEventではない。

### 9.3 巻構成と長期軸

| 段階 | 採用した方向性 |
|---|---|
| 第1巻 | 魔法鑑定士との共同研究。術式・記録・再現・コピーと参照・遠隔実行 |
| 第2巻 | 別国籍の地球出身材料系技術者と出会う。異世界では鍛冶屋で冶金に関わる |
| 第3巻 | さらに別国籍のゲノム・生命系技術者と出会う。異世界では評判の薬師 |
| 長期 | 分野と仲間を増やし、研究所や古代都市管理システムの探究へ進む |

第1巻には「まだ製造されていない装置の故障報告」という謎、コピーと思った魔法が元の術者を遠隔で呼び出していた秘密、共同研究者の鑑定士が犯罪容疑で逮捕される構想がある。記録の真正性・出所、犯罪内容、遠隔実行経路、真相の証明方法は未定。痕跡が鑑定士を指すことから本人の実行を確定しない。

**仲間が専門性を持ち寄り、魔法力の正体・成立条件・規模と限界を解明することは、採用済みの長期方針**である。ソフトウェア→分子・材料→ゲノム・生命→古代都市管理システムという流れを置き換えない。発見順序・答え・巻ごとの開示は未定。「分子系の仲間が水の再構成に気づく」は候補で、第2巻を砂漠舞台に固定していない。転移解析も候補。魔法力・転移・古代都市・大気微量成分を同一原因にまとめない。
